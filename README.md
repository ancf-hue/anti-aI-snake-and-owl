  # 🐍🦉 Анти ИИ: Змея и Сова 

> **Бесплатный социальный офлайн-проект** в рамках инициативы *Anti-AI Shield*.  
> 3D-игра, развивающая внимательность, реакцию и навыки цифровой гигиены через метафору осознанного движения.



---

## 📖 Описание
«Змея и Сова» — это уникальная 3D-игра, работающая **полностью офлайн** в любом современном браузере. Вам предстоит управлять стеклянной змеёй, чтобы украсть золотое яйцо из гнезда мудрой Совы. 

Главная механика вдохновлена игрой «Замри»: когда Сова просыпается и открывает глаза, любое движение змеи приводит к провалу. Игра учит осознанности, контролю импульсов и терпению, что является важной частью цифровой гигиены в эпоху клипового мышления и ИИ-манипуляций.

## ✨ Ключевые особенности
- 🔒 **100% Офлайн и Приватность**: Никакой рекламы, аналитики, трекеров или сбора данных. Игра работает локально в вашем браузере.
- 💎 **Стеклянный 3D-дизайн (Glassmorphism)**: Уникальная визуальная эстетика с использованием `Three.js`, полупрозрачных материалов, динамического освещения и свечения.
- 📱 **Кроссплатформенность**: Адаптивное управление как для ПК (клавиатура), так и для мобильных устройств (сенсорные кнопки с поддержкой тактильной отдачи).
- 🧠 **Развитие навыков**: Тренировка периферического зрения, реакции и способности быстро принимать решения в условиях меняющихся правил.
- 🏆 **Интеграция с Доской почёта**: Возможность сохранить свой результат в общей системе достижений проектов Anti-AI.

## 🎮 Как играть
1. **Цель**: Добраться до гнезда и забрать золотое яйцо за отведённое время (3 минуты).
2. **Сова спит (😴)**: Ползите вперёд, управляйте скоростью и обходите деревья.
3. **Сова просыпается (⚠️)**: Приготовьтесь замереть!
4. **Сова смотрит (🦉)**: **ЗАМРИТЕ!** Любое движение (или прыжок) приведёт к потере жизни.
5. **Управление**:
   - **ПК**: Стрелки `←` `→` (поворот), `↑` `↓` (скорость), `Пробел` (прыжок).
   - **Мобильные**: Экранные стеклянные кнопки (слева — поворот, справа — прыжок и скорость).

## 🛠 Технологический стек
- **Ядро**: Vanilla JavaScript (ES6+)
- **3D-графика**: Three.js (v0.157.0)
- **Стили**: CSS3 (Glassmorphism, анимации, адаптивная вёрстка, `safe-area-inset` для мобильных)
- **Звук**: Web Audio API (генерация звуков без внешних файлов) + Web Speech API (голосовые подсказки)
- **Хостинг**: GitHub Pages (не требует бэкенда)
